# Masai Training

Java assignments, exercises, notes, and mini-projects completed during Masai training. The repository progresses from core Java and object-oriented programming to collections, algorithms, concurrency, and Spring.

## Repository layout

Work is grouped by week and, where applicable, by training day:

```text
src/com/hdfc/
├── Week1/   Core Java and object-oriented programming
├── Week2/   Collections and design-pattern exercises
├── Week3/   Exceptions, lambdas, functional interfaces, and method references
├── Week4/   OOP mini-projects and the HDFC Life policy system
├── Week5/   Arrays, two-pointer algorithms, and threads
├── Week6/   Linked lists, stacks, queues, and the HDFC Life claim pipeline
└── Week7/   Spring Core and Spring Boot examples
```

The usual learning path is:

```text
Week(n) -> day(n) -> assignment or example
```

## Working with the examples

The repository contains independent Java examples rather than one single build. Open the required source directory in an IDE, or compile a selected package with a JDK installed locally. Most examples expose their demonstration logic from a `main` method; the self-contained project READMEs document their source layout and expected behavior.

Generated IDE and compiler output should not be treated as source material. The authoritative code is under `src/`.

## Learning areas

- Java syntax, control flow, classes, constructors, inheritance, interfaces, and polymorphism
- Collections, generics, iterators, maps, sets, queues, and priority queues
- Exception handling and custom exceptions
- SOLID principles and Factory, Strategy, Observer, Singleton, and related patterns
- Arrays, linked lists, stacks, queues, recursion, searching, sorting, and sliding windows
- Threads, executors, futures, producer-consumer coordination, and thread safety
- Spring Core XML configuration, annotation-based configuration, and Spring Boot
